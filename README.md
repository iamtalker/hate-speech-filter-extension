# 혐오표현 필터 (Hate Speech Filter)

지역·성별·인종 등에 대한 혐오·비하 표현이 포함된 글을 자동으로 감지해 블러 처리하는 크롬 확장프로그램입니다.

**Chrome 웹 스토어에서 설치**: https://chromewebstore.google.com/detail/%ED%98%90%EC%98%A4%ED%91%9C%ED%98%84-%ED%95%84%ED%84%B0/nifmepekakeclkfiolnnlgmfhfmigihk

## 왜 "차단"이 아니라 "필터"인가

혐오·차별 표현을 막으려는 시도는 구조적인 한계가 있습니다. 말할 능력과 의지가 있는 사람을 강제로 틀어막는 건 사실상 불가능에 가깝습니다. 그 표현이 옳으냐 그르냐를 떠나서, 원천 봉쇄 자체가 비효율적이라는 뜻입니다. 계정을 막으면 새 계정을 만들고, 특정 단어를 막으면 초성이나 은어로 우회하고, 한 플랫폼을 규제하면 다른 곳으로 옮겨갈 뿐입니다.

그래서 이 확장 프로그램은 표현 자체를 막으려 하지 않습니다. 대신 무엇이 바람직하지 않은 표현인지 정의하고, 그것을 보지 않을 수단을 보는 사람에게 쥐여주는 쪽을 택했습니다. 말하는 사람을 통제하는 게 아니라, 보는 사람에게 시야를 선택할 권리를 돌려주는 것입니다. (그래도 지역명·성별·국적 같은 중립적인 단어 자체는 절대 걸러내지 않는다는 원칙은 지킵니다 — 아래 설계 원칙 참고)

## 설계 원칙

### 왜 "전라도", "여성" 같은 단어 자체는 차단하지 않는가

가장 단순하게 만들려면 "전라도"라는 단어 자체를 금지어로 등록하면 됩니다. 하지만 그러면 "전라도 여행 다녀왔어요", "전라도 음식 맛집 추천" 같은 아무 문제 없는 문장까지 전부 가려지고 맙니다. "전라도"는 지역을 가리키는 정당한 이름일 뿐이고, 죄가 있는 건 그 단어가 아니라 그 단어를 이용해 비하하는 맥락입니다. 단어 자체를 막아버리면 혐오표현 필터링이 아니라 그 단어에 대한 검열이 되어버립니다.

그래서 "여성", "전라도", "중국인" 같은 **집단 식별어는 그 자체로는 절대 차단 대상에 넣지 않습니다.**

### 대신 두 가지 조건으로만 판단합니다

1. **명백한 멸칭/비하 합성어** — "전라디언", "한남충"처럼 그 단어 자체가 이미 비하 목적 외에는 쓰일 일이 거의 없는 단어는 등장 즉시 차단합니다.
2. **중립 단어 + 모호한 비하 표현의 조합** — "홍어"는 생선 이름이기도 하지만, 지역차별 맥락에서 멸칭으로도 쓰입니다. 이런 단어는 단독으로는 차단하지 않고, "전라도" 같은 중립 단어와 **같은 문단 안에 함께** 등장할 때만 차단합니다.

예를 들어 "전라도 홍어 맛집 추천"은 안 걸리지만(생선 얘기), "전라도는 다 홍어다"는 걸립니다(멸칭 조합). **똑같은 단어("홍어")라도 옆에 뭐가 같이 있는지에 따라 판단이 갈리는 것**이 이 필터의 핵심 로직입니다. (참고로 "홍어"는 실제로 생선 이름이자 지역 비하 멸칭으로도 쓰이는 단어라, 이 로직을 설명하기에 가장 적합한 예시입니다.)

전부 로컬 정규식 매칭으로만 동작하며, 외부 API 호출이나 LLM 추론은 사용하지 않습니다. 모든 처리는 브라우저 안에서 끝나며, 어떤 텍스트도 외부로 전송되지 않습니다. 서버도, 계정도, 로그도 없습니다.

## 설치 방법

가장 쉬운 방법은 위 Chrome 웹 스토어 링크에서 "Chrome에 추가"를 누르는 것입니다.

직접 빌드해서 최신 개발 버전을 쓰고 싶다면 개발자 모드로 설치할 수 있습니다.

1. `chrome://extensions` 접속
2. 우측 상단 "개발자 모드" 켜기
3. "압축해제된 확장 프로그램을 로드합니다" 클릭
4. 이 폴더(`hate-speech-filter-extension`) 선택

## 기능

- 표시 방식 선택 가능: **블러 처리**(흐리게, 클릭하면 보기) / **숨기기**(안 보임, 클릭하면 보기) / **완전 삭제**(배지도 없이 흔적 없이 사라짐, 복구 불가)
- 카테고리를 직접 생성/삭제/이름 변경 가능 (지역차별·성차별 같은 고정 카테고리가 아니라 전부 사용자 데이터)
- 카테고리별 on/off
- 카테고리별로 집단 식별어 / 명백한 멸칭 / 모호한 표현 단어를 각각 확인하고 직접 추가·삭제 가능
- "기본 카테고리로 초기화"로 최초 제공되던 지역/성별/인종·국적/장애 카테고리로 되돌리기 가능
- "전체 삭제"로 카테고리를 한 번에 모두 비우기 가능
- 카테고리(단어 설정)를 JSON 파일로 내보내기/가져오기 가능 (백업, 다른 기기/사용자와 공유)
- 제외 사이트 등록 가능 — 등록한 사이트(및 서브도메인)에서는 확장 프로그램이 아예 동작하지 않음. 주소에 경로나 검색조건을 붙이면(`example.com/board?id=3`) 그 페이지에서만 제외됨(적은 key=value가 모두 있으면 해당, 다른 파라미터나 순서는 무관). "현재 사이트 추가" / "현재 페이지 추가" 버튼으로 원클릭 등록
- 감지된 글은 삭제가 아니라 블러 처리 후 클릭하면 다시 볼 수 있음

## 확장 단어 팩 (선택 사항)

기본 제공 카테고리는 일부러 작게 유지하고 있습니다(개인 맞춤형 도구라는 정체성 때문입니다 — [설계 원칙](#설계-원칙) 참고). 대신 더 넓은 커버리지를 원하는 사람을 위해 [`wordpacks/extended-word-pack.json`](wordpacks/extended-word-pack.json)에 **세대차별·성차별·지역차별·민족차별·인종·국적차별·장애 비하** 6개 카테고리로 구성된 확장 단어 팩을 선택 사항으로 제공합니다. 팩은 기본 목록의 모든 단어를 포함하는 상위 집합이라서, 기본 카테고리로 초기화한 뒤 팩을 설치하면 이전 상태 이상으로 복원됩니다.

**설치 방법**: 팝업의 카테고리 섹션 우측 상단, "기본 카테고리로 초기화" 아래에 있는 **"확장 단어 팩 설치"** 버튼을 누르면 됩니다. 팩은 확장 프로그램에 함께 들어 있어서 외부에서 받아오지 않으며(인터넷 요청 없음), 누르기 전까지는 아무것도 추가되지 않습니다. 기존 카테고리와 단어는 그대로 두고, 이름이나 id가 같은 카테고리에는 없는 단어만 합치고, 없는 카테고리는 새로 만듭니다. 여러 번 눌러도 중복 추가되지 않습니다.

JSON 파일을 직접 다루고 싶다면 팝업의 "가져오기"로 `wordpacks/extended-word-pack.json`을 불러올 수도 있습니다. 이 경우는 병합이 아니라 **현재 카테고리를 전부 대체**하므로, 커스터마이징한 내용이 있다면 먼저 "내보내기"로 백업해두세요.

기본 카테고리와 똑같은 원칙(집단 식별어는 단독 차단 안 함 / 명백한 멸칭은 즉시 차단 / 모호한 표현은 조합될 때만 차단)으로 구성했습니다.

## 폴더 구조

```
manifest.json      확장프로그램 설정 (Manifest V3)
wordlists.js        최초 설치 시 시드로 쓰이는 기본 카테고리/단어 목록
settings-utils.js   설정 정규화, 구버전 데이터 마이그레이션 (공통 유틸)
content.js          페이지 스캔 및 블러 처리 로직
background.js       설치 시 기본 설정 초기화
popup.html/js/css   팝업 설정 UI (카테고리 생성/삭제/단어 편집)
styles.css          블러/배지 스타일
icons/              툴바/스토어용 아이콘 (16/48/128px, 확장프로그램 패키지에 포함됨)
store-assets/        스토어 등록 전용 이미지 (프로모션 타일 등, 패키지에는 미포함)
wordpacks/            선택 설치용 확장 단어 팩 (패키지에 포함, 팝업의 "확장 단어 팩 설치" 버튼으로 병합)
package.ps1          Chrome 웹 스토어 업로드용 zip 생성 스크립트 (dist/에 생성)
PRIVACY.md           개인정보처리방침 (스토어 등록용)
STORE_LISTING.md      스토어 등록용 설명문/체크리스트 초안
```

## Chrome 웹 스토어 등록

1. `powershell -File package.ps1` 실행 → `dist/`에 업로드용 zip 생성
2. [Chrome 웹 스토어 개발자 콘솔](https://chrome.google.com/webstore/devconsole)에서 계정 등록 (최초 1회 5달러)
3. zip 업로드, `STORE_LISTING.md`의 설명문/개인정보처리방침 URL 입력, 스크린샷 첨부
4. 심사 제출

자세한 체크리스트는 [STORE_LISTING.md](STORE_LISTING.md) 참고.

## 알려진 한계

- 규칙 기반이라 신조어·변형 표현은 목록에 없으면 걸러지지 않습니다. 팝업에서 사용자 지정 단어를 추가해 보완할 수 있습니다.
- 설정을 바꾸면 새로고침 후 적용됩니다.
