# 혐오표현 필터 (Hate Speech Filter)

지역·성별·인종 등에 대한 혐오·비하 표현이 포함된 글을 자동으로 감지해 블러 처리하는 크롬 확장프로그램입니다.

## 설계 원칙

지역명, 성별, 국적 같은 **중립적인 집단 식별어 자체는 차단하지 않습니다.** 이런 단어는 정상적인 문맥에서도 흔히 쓰이기 때문입니다.

대신 다음 두 조건 중 하나를 만족할 때만 글을 블러 처리합니다.

1. 다른 용도로 쓰일 여지가 거의 없는 **명백한 멸칭/비하 합성어**가 등장했을 때
2. **중립 단어**(예: "전라도")와 **다른 뜻도 있는 모호한 비하 표현**(예: "홍어")이 **같은 문단 안에 함께** 등장했을 때

전부 로컬 정규식 매칭으로만 동작하며, 외부 API 호출이나 LLM 추론은 사용하지 않습니다.

## 설치 방법 (개발자 모드)

1. `chrome://extensions` 접속
2. 우측 상단 "개발자 모드" 켜기
3. "압축해제된 확장 프로그램을 로드합니다" 클릭
4. 이 폴더(`hate-speech-filter-extension`) 선택

## 기능

- 카테고리별 on/off (지역차별 / 성차별 / 인종·국적차별 / 장애 비하)
- 카테고리별 "포함된 단어 보기"로 실제 필터링 단어 목록 확인 가능
- 사용자 지정 차단 단어 추가/삭제
- 감지된 글은 삭제가 아니라 블러 처리 후 클릭하면 다시 볼 수 있음

## 폴더 구조

```
manifest.json     확장프로그램 설정 (Manifest V3)
wordlists.js       기본 단어 목록 (집단어 / 명백한 멸칭 / 모호한 멸칭)
content.js         페이지 스캔 및 블러 처리 로직
background.js      설치 시 기본 설정 초기화
popup.html/js/css  팝업 설정 UI
styles.css         블러/배지 스타일
```

## 알려진 한계

- 규칙 기반이라 신조어·변형 표현은 목록에 없으면 걸러지지 않습니다. 팝업에서 사용자 지정 단어를 추가해 보완할 수 있습니다.
- 설정을 바꾸면 새로고침 후 적용됩니다.
